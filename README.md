# station-timer

試験やイベントの進行に使う、ブラウザーで動作するタイマーです。経過時間に合わせて画面にメッセージを表示し、必要に応じて音声を再生します。

## 起動方法

このアプリはHTML、CSS、JavaScriptだけで動作し、インストールやビルドは不要です。

1. このフォルダーをパソコンに保存します。
2. `index.html`をブラウザーで開きます。
3. 下部の「CSV読込」から進行表のCSVファイルを選びます。
4. 読み込みが完了したら「開始」を押します。

音声を使う場合は、`audio`フォルダーも`index.html`と同じフォルダーに置いてください。ブラウザーの設定や環境によってローカルファイルの読み込みに制限がある場合は、このフォルダーをローカルWebサーバーで公開してアクセスしてください。

Python 3がインストールされている場合は、プロジェクトフォルダーで次のコマンドを実行するとローカルWebサーバーを起動できます。ブラウザーで`http://localhost:8000`を開き、終了するときはコマンドを実行した画面で`Ctrl+C`を押します。

```sh
python -m http.server 8000
```

## 進行表CSVの作り方

CSVの1行目に列名を書き、2行目以降にイベントを記入します。必須列は`time`と`message`です。列名は大文字・小文字を区別せず、前後の空白は無視されます。

```csv
time,message,audio
00:00,試験を始めてください,start.mp3
02:30,残り30秒です,remain30.mp3
03:00,終了です,end.mp3
```

### 列の説明

| 列名 | 必須 | 内容 |
| --- | --- | --- |
| `time` | はい | タイマー開始からの経過時間。`MM:SS`または`HH:MM:SS`で指定します。 |
| `message` | はい | その時刻に画面へ表示するメッセージ。 |
| `audio` | いいえ | 再生する音声ファイル名。`audio`フォルダー内のファイルを指定します。 |
| `candidate` | いいえ | そのイベントで表示する追加情報。受験番号や対象者名などに使えます。 |

音声が不要な場合は、`audio`列そのものを省略できます。列を残したまま、音声を鳴らさない行だけ空欄にすることもできます。

```csv
time,message
00:00,試験を始めてください
02:30,残り30秒です
03:00,終了です
```

### 時刻とCSVの注意点

- 時刻は時計の時刻ではなく、タイマー開始後の経過時間です。`00:00`のイベントは開始直後に実行されます。
- `MM:SS`では分と秒、`HH:MM:SS`では時・分・秒を指定します。分と秒は`00`から`59`までです。例：`2:30`、`00:02:30`。
- イベントの行は時刻順でなくても構いません。読み込み時に時刻順に並べ替えます。
- 同じ時刻のイベントは指定できません。重複があるとCSV全体を読み込めません。
- `candidate`などの任意列を追加できます。列の順番は自由です。
- メッセージやファイル名にカンマを含める場合は、その項目を二重引用符で囲みます。例：`00:10,"前半,終了です"`。
- CSVはUTF-8形式で保存してください。表計算ソフトで作成した場合は、CSV形式で保存します。

## 音声ファイル

音声ファイルはプロジェクト内の`audio`フォルダーに置き、CSVの`audio`列にはファイル名と拡張子を記入します。たとえば`audio/start.mp3`を使う場合、CSVには`start.mp3`と記入します。

指定した音声ファイルが見つからない場合は警告が表示されます。警告が出ても、CSVに問題がなければタイマーは読み込まれ、メッセージ表示も利用できます。音声を再生しないイベントでは、`audio`を空欄にするか列を省略してください。

## 操作方法

| ボタン | 動作 |
| --- | --- |
| CSV読込 | 進行表CSVを選びます。タイマーが停止中に利用できます。 |
| 開始 | 00:00:00から計測を始め、時刻に応じたイベントを実行します。 |
| 一時停止 | 計測を止めます。再開すると停止した時点から続けます。 |
| 再開 | 一時停止した計測を続けます。 |
| 停止 | 計測をリセットし、経過時間を00:00:00に戻します。次に開始するとイベントも最初から実行されます。 |
| 全画面表示 | 全画面表示を切り替えます。全画面中は操作ボタンが隠れます。画面下部にマウスポインターを移動するか、ボタンにフォーカスすると表示できます。 |

イベントの時刻になると、画面中央のメッセージが更新され、`candidate`列に値があれば追加情報も表示されます。音声が指定されていれば、その音声も再生されます。最後のイベントの後もタイマーは自動停止せず、停止ボタンを押すまで計測を続けます。

## エラー・警告

- CSVの列名不足、時刻の形式不正、同一時刻の重複などがあると、問題の内容が画面に表示されます。CSVを修正して再度読み込んでください。
- 音声ファイルが見つからない場合は警告として表示されます。音声ファイル名や`audio`フォルダーの場所を確認してください。音声が不要なら、CSVで`audio`列を省略するか該当セルを空欄にします。
- ブラウザーが音声再生を許可しない場合は、開始または再開ボタンを押してからご利用ください。
